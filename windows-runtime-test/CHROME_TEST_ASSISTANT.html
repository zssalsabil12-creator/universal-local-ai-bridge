  • Loaded the extension in Chrome (chrome://extensions/)
  • Opened the extension side panel

🔧 Basic Functionality
Extension Loaded
Verify the ULAB extension is loaded in Chrome
  1. Go to chrome://extensions/
  2. Verify "Universal Local AI Bridge" is listed
  3. Verify no errors are shown
Side Panel Opens
Verify the side panel opens when clicking the extension icon
  1. Click the ULAB icon in the Chrome toolbar
  2. Verify the side panel opens on the right
  3. Verify no console errors (F12 → Console)
Agent Connected
Verify the extension can connect to the Local Agent
  1. Click "Connect Agent" in the side panel
  2. Verify status changes to "Connected"
  3. Verify green indicator appears
📁 Project Operations
Project Selected
Verify you can select and load a project
  1. Click "Select Project"
  2. Choose the test-project folder
  3. Verify the project loads successfully
Project Tree Works
Verify the file tree displays correctly
  1. Expand directories in the tree
  2. Verify files display correctly
  3. Verify file sizes are shown
Search Works
Verify search functionality works
  1. Type "auth" in the search box
  2. Verify results appear
  3. Verify src/auth/login.ts is in results
Safe File Opens
Verify you can open safe files
  1. Click on src/app.ts
  2. Verify content displays
  3. Verify line numbers are shown
🔒 Security Tests
.env Blocked
Verify sensitive files are blocked
  1. Try to read .env file
  2. Verify access is denied
  3. Verify error message is shown
Outside-Project Path Blocked
Verify paths outside the project are blocked
  1. Try to access ../../secret.txt
  2. Verify access is denied
  3. Verify error message is shown
📝 File Operations
Safe File Created
Verify you can create safe files
  1. Create test-output.txt
  2. Verify file is created
  3. Verify content is correct
Safe Modification Approved
Verify you can modify files with approval
  1. Modify test-output.txt
  2. Verify permission prompt appears
  3. Approve the modification
  4. Verify file is updated
Diff Shown
Verify diff is shown before applying changes
  1. View diff before/after modification
  2. Verify changes are displayed
  3. Verify line numbers are correct
