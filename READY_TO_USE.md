## 🚀 Quick Start (3 Steps)

### Step 1: Extract
- **Windows**: Right-click → Extract All
- **Mac**: Double-click
- **Linux**: `unzip ulab-v1.0.0.zip`

### Step 2: Install
Open Terminal/Command Prompt in the extracted folder:
```bash
npm install
```

### Step 3: Run
```bash
node start.js
```

That's it! The app will open automatically at **http://localhost:5173**

## 🔧 Troubleshooting

### App doesn't start?
```bash
# Check Node.js version (need v18+)
node --version

# Reinstall dependencies
rm -rf node_modules package-lock.json
npm install
```

### Port 5173 is busy?
```bash
npm run dev -- --port 3000
```
