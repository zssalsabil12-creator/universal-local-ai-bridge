# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.3.0] - 2025-01-XX

### Added
- **Diff Viewer**: Professional diff viewer with unified and split views
- **Context Builder**: Enhanced context building with file pinning and exclusion
- **Welcome Modal**: Improved onboarding experience for new users
- **Notification System**: Real-time notifications for user actions
- **Keyboard Shortcuts Modal**: Comprehensive keyboard shortcuts reference
- **Task History**: Complete task tracking with filters and search
- **Local Memory**: Project-specific memory with decisions, rules, and preferences
- **Permission Center**: Advanced permission management with path-based rules
- **Approval Modal**: Professional approval system with diff preview
- **Agent Mode**: AI as local agent with command execution
- **AI Bridge Panel**: Connect to 10+ AI providers with custom prompts
- **ULP Protocol**: Universal Local Protocol for AI integration
- **Prompt Generator**: Smart prompt generation for each AI provider

### Enhanced
- Improved workspace layout with more panels
- Better file tree navigation
- Enhanced search functionality
- Improved syntax highlighting
- Better responsive design

## [0.2.0] - 2025-01-XX

### Added
- **Git Panel**: View git status, branches, and commits
- **Terminal Panel**: Run commands with permission control
- **Settings Panel**: Customize ULAB behavior
- **Operation Log**: Track all operations
- **AI Comparison**: Compare responses from multiple AI providers
- **Project Map**: Visual representation of project structure
- **Demo Mode**: Try ULAB without a real project

### Enhanced
- Improved file system access
- Better context extraction algorithm
- Enhanced syntax highlighting
- Improved performance

## [0.1.0] - 2025-01-XX

### Added
- **Landing Page**: Professional landing page with all features
- **Workspace**: Main workspace with file tree and code viewer
- **File System Access**: Read and navigate local files
- **Context Engine**: Smart context extraction
- **Basic AI Integration**: Copy context to AI chatbots

- **Demo Project**: Sample project for testing

### Features
