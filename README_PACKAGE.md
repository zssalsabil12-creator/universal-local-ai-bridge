## 📖 Quick Guide

### What is ULAB?
Universal Local AI Bridge connects AI chatbots (ChatGPT, Gemini, etc.) to your local projects, allowing you to:
- Search your project files intelligently
- Get AI assistance with accurate context
- Maintain complete privacy (everything stays local)

### How to Use

1. **Select Project**
   - Click "Select Project" in the app
   - Choose your project folder
   - Wait for indexing

2. **Ask Questions**
   - Type in the search box
   - Examples:
     - "Where is authentication handled?"
     - "How is the database accessed?"
     - "Where are the UI components?"

3. **Use Context**
   - Click "Copy Context"
   - Paste into ChatGPT, Gemini, or any AI
   - Get accurate answers

## 🔧 Troubleshooting

### Node.js not installed?
Download from: https://nodejs.org/
Need version 18 or higher

### Port 5173 is busy?
```bash
npm run dev -- --port 3000
```

### Dependencies won't install?
```bash
rm -rf node_modules package-lock.json
npm install
```
