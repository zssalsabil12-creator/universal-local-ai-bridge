## 🚀 Quick Start (3 Steps)

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Application
```bash
node start.js
```

### 3. Open Browser
Opens automatically at: **http://localhost:5173**

## 📖 Usage

1. **Select Project** - Click "Select Project" and choose your folder
2. **Ask Questions** - Type in search box
3. **Copy Context** - Click "Copy Context" and paste into AI

## 🔧 Troubleshooting

### Node.js not installed?
Download: https://nodejs.org/ (need v18+)

### Port busy?
```bash
npm run dev -- --port 3000
```

### Dependencies won't install?
```bash
rm -rf node_modules package-lock.json
npm install
```
