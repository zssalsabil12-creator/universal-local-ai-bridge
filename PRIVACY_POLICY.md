# Privacy Policy

**Last Updated**: 2026-09-13

---

## Introduction

Universal Local AI Bridge ("ULAB", "we", "us", or "our") is committed to protecting your privacy. This Privacy Policy explains how we handle your data when you use our software.

**Key Principle**: ULAB is a local-first application. Your data stays on your device.

---

## What We Collect

### We Do NOT Collect

ULAB does **NOT** collect, store, or transmit:

❌ **Personal Information**
- Names, email addresses, phone numbers
- Physical addresses
- Payment information
- Identification numbers

❌ **Project Data**
- Source code files
- Project files
- Configuration files
- Build artifacts
- Git history

❌ **Usage Data**
- Usage patterns
- Feature usage
- Session data
- Analytics data
- Telemetry data

❌ **Technical Data**
- IP addresses
- Device identifiers
- Browser fingerprints
- Network information
- System information

### What Stays Local

All of the following remain **entirely on your device**:

✅ **Project Data**
- Project files and metadata
- File indexes
- Search results
- Context packages

✅ **Application Data**
- Settings and preferences
- Memory entries
- Operation logs
- Permissions

✅ **Temporary Data**
- Rollback snapshots
- Cache data
- Session state

## Third-Party Services

### AI Providers

When you use ULAB with AI providers (ChatGPT, Gemini, DeepSeek, etc.):

**What You Send**:
- Context you intentionally copy and paste
- Your questions
- File contents you select

**What We Control**:
- Nothing. You control what you send.

**What Providers Control**:
- Their own data handling
- Their own privacy policies
- Their own data retention

**Important**: When you send data to an AI provider, that provider's privacy policy applies, not ours. Review their policies before use.

### Browser Extensions

ULAB Chrome Extension:
- Uses only Chrome Extension APIs
- No external dependencies
- No third-party services
- No data transmission to us

## Data Storage

### Local Storage

ULAB stores data locally on your device:

**Location**:
- Project index: In project folder
- Settings: Browser local storage
- Memory entries: Browser local storage
- Operation log: Browser local storage

**Retention**:
- Until you delete it
- Until you clear ULAB data
- Until you uninstall ULAB

**Your Control**:
- You can delete all data anytime
- You can export data before deletion
- You control what's stored

### No Cloud Storage

ULAB does **NOT** use:
- Cloud databases
- Remote storage
- Cloud synchronization
- Backup services
- Analytics services

---

## Network Activity

### ULAB Network Usage

ULAB makes **NO** network requests except:

1. **Optional Updates** (if enabled):
   - Check for new versions
   - Download updates
   - You control this feature

2. **User-Initiated**:
   - You copy context to AI
   - You paste into AI chatbot
   - AI provider makes requests

### No Hidden Activity

ULAB does **NOT**:
- Phone home
- Send telemetry
- Upload data
- Sync to cloud
- Contact external servers

## Your Rights

### Data Rights

You have the right to:

✅ **Access** - View all your data
✅ **Delete** - Delete all your data
✅ **Export** - Export your data
✅ **Control** - Control what's stored
✅ **Portability** - Move your data

### How to Exercise Rights

**Delete All Data**:
1. Open ULAB
2. Go to Settings
3. Click "Clear All Data"
4. Confirm deletion

**Export Data**:
1. Open ULAB
2. Go to Settings
3. Click "Export Data"
4. Save export file

**Uninstall**:
1. Run uninstaller
2. Follow prompts
3. All data removed
