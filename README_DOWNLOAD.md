# 🚀 Universal Local AI Bridge (ULAB) - دليل التحميل والتشغيل

## 📦 تحميل الحزمة

### الطريقة 1: التحميل المباشر
1. افتح صفحة التحميل: `download.html`
2. اضغط على **"تحميل الحزمة الكاملة"**
3. احفظ الملف `ulab-v1.0.0.zip`

### الطريقة 2: من سطر الأوامر
```bash
# إذا كنت في مجلد المشروع
npm run build
```

---

## ⚡ التشغيل السريع (3 خطوات فقط)

### الخطوة 1: فك الضغط
- **Windows**: انقر بزر الماوس الأيمن → استخراج الكل
- **Mac**: انقر مزدوجاً على الملف
- **Linux**: `unzip ulab-v1.0.0.zip`

### الخطوة 2: تثبيت المكتبات
افتح Terminal أو Command Prompt في مجلد المشروع:
```bash
npm install
```

### الخطوة 3: التشغيل
```bash
node start.js
```

أو:
```bash
npm run dev
```

## 📖 الاستخدام

### 1. اختيار المشروع
- اضغط **"اختيار مشروع"**
- اختر مجلد المشروع
- انتظر الفهرسة

### 2. طرح الأسئلة
- اكتب سؤالك في مربع البحث
- أمثلة:
  - "أين يتم التحقق من المصادقة؟"
  - "كيف يتم التعامل مع قاعدة البيانات؟"

### 3. استخدام السياق
- اضغط **"نسخ السياق"**
- الصق في ChatGPT أو Gemini
- احصل على إجابات دقيقة
